CodePull - 远程服务器 Git 拉取工具

CodePull 是一个基于 Python + PySide6 开发的桌面工具，用于通过 SSH 连接远程服务器批量执行 Git 拉取操作。

工具读取本地 config.json 中的服务器和项目配置，在界面中列出可选项目，用户勾选后即可一键执行远程更新，适合日常测试环境或部署环境的代码同步场景。
