ImagePreviewer - 本地图片预览工具

项目简介

ImagePreviewer 是一个简洁高效的本地图片预览工具，基于 Python + PyQt6 开发。支持缩略图浏览、大图预览、智能缓存和多格式图片查看。

GitHub 地址：https://github.com/PanNinan/ImagePreviewer

主要功能

功能 说明
📁 文件夹浏览 选择任意文件夹，自动扫描并显示图片
🔍 缩略图预览 左侧栏显示所有图片的缩略图，支持异步加载
🖼️ 大图浏览 点击缩略图查看大图，支持键盘左右切换
💾 智能缓存 缩略图自动缓存到本地，下次打开秒速加载
🎯 格式支持 JPG、JPEG、PNG、BMP、WebP
⌨️ 快捷键支持 ← → 方向键快速切换图片
🧹 缓存管理 一键清除缩略图缓存

技术栈

组件 用途
PyQt6 GUI 框架
Pillow (PIL) 图像处理与缩略图生成
Python 3.8+ 运行环境
PyInstaller 打包为可执行文件

快速开始

方式一：下载 EXE（推荐）

  1. 访问 Releases 页面下载 ImagePreviewer.exe
  2. 双击即可运行，无需安装 Python

方式二：源码运行

基本操作

  1. 启动程序
  2. 点击「选择文件夹」按钮，选择包含图片的目录
  3. 点击左侧缩略图查看大图，或使用 ← → 方向键切换
  4. 菜单栏「工具」→「清除缩略图缓存」可清理缓存

缓存位置

  • Windows：%USERPROFILE%\.image_previewer_cache
  • macOS/Linux：~/.image_previewer_cache

已知问题

  1. 大图片首次加载较慢（缩略图生成需要时间）
  2. WebP 动图仅显示第一帧，不支持动画
