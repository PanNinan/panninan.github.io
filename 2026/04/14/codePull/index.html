CodePull - 远程服务器 Git 拉取工具

项目简介

CodePull 是一个基于 Python + PySide6 开发的桌面工具，用于通过 SSH 连接远程服务器批量执行 Git 拉取操作。

工具读取本地 config.json 中的服务器和项目配置，在界面中列出可选项目，用户勾选后即可一键执行远程更新，适合日常测试环境或部署环境的代码同步场景。

GitHub 地址：https://github.com/PanNinan/codePull

主要功能

功能 说明
🔐 SSH 远程连接 支持通过 SSH 连接远程 Linux 服务器
📁 多项目管理 支持配置多个项目目录及对应 Git 分支
🚀 批量拉取 支持勾选一个或多个项目批量执行 Git Pull
📋 全选/取消全选 提供快捷操作按钮
📝 实时日志 实时显示执行日志，方便查看拉取过程
⚙️ 自动生成配置 首次启动时自动生成默认 config.json
📦 一键打包 支持使用 PyInstaller 打包为 Windows .exe 可执行文件
🤖 CI/CD 自动发布 提供 GitHub Actions 自动打包并发布 Release

技术栈

类别 技术/工具
开发语言 Python 3.8+
GUI 框架 PySide6
SSH 通信 Paramiko
打包工具 PyInstaller
CI/CD GitHub Actions

快速开始

方式一：下载 EXE（推荐）

  1. 前往 Releases 页面下载最新 CodePullTool.exe 和 config.json
  2. 将两个文件放到同一目录
  3. 编辑 config.json，填入真实服务器信息
  4. 双击 CodePullTool.exe 运行

界面预览

工具提供简洁直观的图形界面：

  • 左侧显示已配置的项目列表
